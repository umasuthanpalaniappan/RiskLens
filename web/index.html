Volatility is the signal.
RiskLens turns it into a portfolio.

An LSTM forecasts each stock's near-term volatility from its own history. A dynamic graph neural network refines that forecast using how volatility moves between stocks. The result feeds a long-only minimum-variance optimiser that rebalances automatically, every trading day, on real market data.

How it works

From raw prices to portfolio weights

Six stages, each doing one job. Nothing here is a black box — every arrow below is a real function in the codebase.

01

Data

Daily close & volume for 18 NSE large/mid-caps, pulled live via yfinance, spanning ~15 years.

02

Features

Log returns, realised volatility, 20-day momentum, and a volume z-score — computed per stock, per day.

03

Graph

A rolling 60-day volatility-correlation graph links stocks whose risk moves together — not just their prices.

04

LSTM

A single-stock LSTM forecasts each stock's volatility ratio from its own history alone — the baseline.

05

Dynamic GNN

A graph convolution refines that forecast using neighbours in the graph. A learned per-stock gate decides how much to trust it.

06

Portfolio

Predicted volatilities + real correlations build Σ. A long-only optimiser solves for minimum variance.

Why volatility, not returns?

Forecasting returns reliably is a much harder, noisier problem than forecasting volatility, which is well known to cluster and be comparatively predictable. RiskLens is honest about only tackling the tractable half of that problem.

Why minimum-variance, not Markowitz?

Classic mean-variance optimisation needs a return forecast too. Since these models predict volatility only, fabricating a return forecast just to run a "real" Markowitz optimiser would mean optimising against a made-up number. Minimum-variance is the honest optimisation for what's actually being forecast.

How true can this be?

An honest reliability read, not a sales pitch.

This is not financial advice. RiskLens is a research/educational project. It forecasts volatility, not returns, and the minimum-variance portfolio it produces makes no claim about expected performance. Backtested direction accuracy measures a narrow thing (5-day volatility direction) on historical data only. Do not act on this output without independent judgement.
