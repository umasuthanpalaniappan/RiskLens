# RiskLens — Midsem Prototype

This folder is the **midsem** version of RiskLens: a simpler, standalone LSTM + Gated GNN
volatility model for 10 Indian banking stocks, with a 2-page Streamlit dashboard.

It is kept separate from the main `app/dashboard.py` at the repo root, which is the
**end-sem** version — an 18-stock universe, min-variance portfolio optimizer, regime
classifier, and daily GitHub Actions automation (see the root `README.md`).

## What's here

- `LSTM.py` — standalone LSTM-only volatility baseline.
- `LSTM_GNN_FINAL.py` — LSTM + Gated GNN model (dynamic 60-day rolling correlation graph,
  threshold 0.65), trains and evaluates against the LSTM baseline, saves plots to `OUTPUT/`.
- `OUTPUT/` — plots generated by the last training run of `LSTM_GNN_FINAL.py`.
- `app.py` — 2-page Streamlit dashboard:
  - **Page 1** (default): live price, day change, 52-week range, market cap for all 10
    stocks, plus a 6-month price trend chart.
  - **Page 2** (reachable only via the "Next →" button — no sidebar link exposes it
    directly): LSTM vs LSTM+GNN direction-accuracy results, the training plots, and a
    live correlation heatmap built the same way the model constructs its graph.
- `requirements.txt` — Python dependencies for the dashboard.

## Running it

```
pip install -r requirements.txt
streamlit run app.py
```

Note: no model checkpoint is saved by `LSTM_GNN_FINAL.py`, so the dashboard's Page 2
shows the locked results from the last recorded training run rather than live inference.
Rerun `LSTM_GNN_FINAL.py` to refresh both the numbers baked into `app.py` and the plots
in `OUTPUT/`.
